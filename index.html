Таблиці.

Рядки, стовпці, заголовки та об'єднані комірки. Пишемо код у браузері, зберігаємо комітами і публікуємо на своєму сайті.

Перед початком

Створи репозиторій tables.

Для кожної теми у нас окремий репозиторій. Цей урок живе в репозиторії tables.

  1. Увійди в GitHub

    Відкрий github.com у браузері (Safari або Chrome, не в застосунку GitHub) і увійди у свій акаунт.

  2. Новий репозиторій

    Натисни + вгорі праворуч → New repository. У полі Repository name напиши tables.

  3. Налаштуй і створи

    Обери Public і постав галочку Add a README file. Натисни зелену кнопку Create repository.

  4. Увімкни GitHub Pages

    Settings → ліворуч Pages. У Branch обери main і / (root) → Save.

За 1–2 хвилини твій сайт з'явиться за адресою:

https://твій-логін.github.io/tables/

Етап 1 · Знайомство з прикладом

Дані в рядках і стовпцях.

Таблиця потрібна, коли дані зручно порівнювати: хто, що, скільки, коли. Набирай кожен приклад у своєму репозиторії і зберігай комітом.

Таблиця підходить
  • Розклад уроків
  • Оцінки за чверть
  • Порівняння цін
  • Результати змагань
Таблиця не підходить
  • Розташувати меню і текст поруч
  • Зробити колонки на сайті
  • Вирівняти картинки
  • Для цього є CSS, ми його ще вивчимо
<table>table

Уся таблиця. Усередині неї лежать рядки.

<tr>table row

Один рядок. Усередині лежать комірки.

<th>table header

Комірка-заголовок. Браузер робить текст жирним.

<td>table data

Звичайна комірка з даними.

Крок 0. Створи файл index.html

Add file → Create new file → назва index.html. Встав каркас і зроби перший коміт. Блок <style> малює лінії таблиці. Без нього таблиця виглядатиме як текст без рамок. Усі приклади нижче дописуй всередину <body>.

Заголовки зі scope
Атрибут scope підказує, до чого належить заголовок: scope="col" — до стовпця, scope="row" — до рядка. На вигляд нічого не змінюється, але програми для незрячих людей читають таку таблицю правильно.

Шпаргалка

      

        

          
Тег або атрибутЩо робить

          
            
<table>Створює таблицю

            
<tr>Рядок таблиці

            
<th>Комірка-заголовок (жирна, по центру)

            
<td>Звичайна комірка з даними

            
<caption>Назва таблиці, одразу після <table>

            
<thead> <tbody> <tfoot>Шапка, основна частина, підсумок

            
colspan="2"Об'єднати 2 комірки по горизонталі

            
rowspan="2"Об'єднати 2 комірки по вертикалі

            
scope="col" / scope="row"Заголовок стовпця / рядка

          
        

      

      
Типова помилка
Після colspan або rowspan забули прибрати зайві <td>. Тоді в рядку стає більше комірок, ніж стовпців, і таблиця «їде» вправо. Порахуй: у кожному рядку має виходити однакова кількість стовпців.

      Екранна клавіатура «виправляє» код
      Планшет може ставити велику літеру на початку рядка чи замінювати лапки " на «ялинки». Через це colspan="2" перестає працювати. Вимкни автовиправлення та розумну пунктуацію в налаштуваннях клавіатури.
